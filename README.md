# Guess the Number Game

**6th Workshop: JavaScript Exploring**

A browser-based number guessing game built with HTML, CSS, and JavaScript.

## How to play
1. Click **Start game**. A JavaScript `prompt()` dialog asks you to enter your guess.
2. The computer randomly selects a whole number from 0 to 10.
3. The game tells you whether your guess is too low, too high, or correct.
4. When you win, choose whether to play another round or quit.

## Run locally
Download or clone this repository, then open `index.html` in your web browser.

## Technologies
- HTML5
- CSS3
- JavaScript

## JavaScript concepts used
- Functions: `playRound()` and `startGame()`
- Random number generation: `Math.random()` and `Math.floor()`
- Conditional statements: `if / else if / else`
- Loops: `while`
- DOM manipulation: `getElementById()` and `textContent`
- Event listeners: `addEventListener()`
- Input validation
- Browser dialogs: `window.prompt()`, `window.alert()`, and `window.confirm()`
