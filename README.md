# Guess the Number Game 🧸

**6th Workshop: JavaScript Exploring**

A cute bear-themed number guessing game built with HTML, CSS, and JavaScript.

## How to play
1. The computer randomly chooses a whole number from 0 to 10.
2. Enter your guess directly in the input field on the webpage.
3. Click **Guess** or press Enter.
4. The game displays whether your guess is too low, too high, or correct.
5. Click **New Game** to play another round.

## Run locally
Download or clone this repository, then open `index.html` in your web browser.

## Technologies
- HTML5
- CSS3
- JavaScript

## JavaScript concepts used
- Functions: `startGame()` and `checkGuess()`
- Random number generation: `Math.random()` and `Math.floor()`
- Conditional statements: `if / else if / else`
- DOM manipulation: `getElementById()`, `textContent`, and `innerHTML`
- Event listeners: `addEventListener()`
- Input validation
- Game state using variables

## GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site. The live URL will appear in the Pages section.
